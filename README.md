# Windows Server IT Support Home Lab

Hands-on Windows Server lab built to practice common IT Support and System Administration tasks.

## Labs

### 1. Active Directory & Domain Join
- Configured Active Directory Domain Services (AD DS)
- Created Organizational Units
- Created and managed users and security groups
- Joined a Windows client to the domain

### 2. DHCP
- Configured DHCP Server
- Created and configured a DHCP scope
- Practiced automatic IP address allocation for clients

### 3. Group Policy
- Configured Group Policy Objects (GPO)
- Applied centralized administrative and security policies
- Tested policies on domain-joined clients

### 4. Volume Management & File Sharing
- Practiced disk volume management
- Configured shared folders
- Configured access permissions
- Tested file access from a client machine

## Skills Practiced

- Windows Server
- Active Directory
- DHCP
- DNS Fundamentals
- Group Policy
- User & Group Management
- File Sharing & Permissions
- Disk Management
- Windows Troubleshooting
- Basic Networking

## Purpose

This project was built as a hands-on learning environment to develop practical IT Support and System Administration skills.
